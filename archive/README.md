# Legacy reference implementation

This directory contains the previous dictionary-based implementations of sampling, KV storage, request scheduling and completion handling. They are retained for interface comparison and implementation history.

| File | Purpose |
| --- | --- |
| `step_solutions.py` | Functional reference for the earlier cache and scheduling interfaces |
| `original_scaffold.py` | Integration driver for those legacy interfaces |

The maintained runtime is in [`kvserve/`](../kvserve/). Run `python scaffold.py` from the repository root to use the current implementation. Published benchmark results are generated by [`benchmarks/run.py`](../benchmarks/run.py).

See [implementation history](../docs/provenance.md) for the migration rationale and [NOTICE.md](../NOTICE.md) for source attribution.
